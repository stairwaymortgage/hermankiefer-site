# HermanKiefer.com

The story of Dr. Herman Kiefer (1825–1911) and his family — Volume Two of *The Kiefer Saga*.

- Static site, hosted on Vercel. Pages are generated by `_src/build.py` (chapters in `_src/chapters.py`).
- Family tree data: `_src/make_tree.py` builds `assets/tree.json` from the master spreadsheet; living relatives are kept private.
- Uploads, comments, sign-ups and tree suggestions go to Supabase (`supabase/schema.sql`); fill `assets/config.js` with the project URL and publishable key.
- Moderation: `/admin` (magic-link sign-in, Jim only).

Rebuild: `cd _src && python3 build.py`
